## 1. 用户认证模块
包含登录功能和注册功能，用户需要登录认证才能进入系统进行诊断和其他操作。
## 2. 首页概览模块
数据概览展示关键业务指标，包括今日诊断次数、新增患者数、病例总数、累计诊断量。快速入口提供主要功能区域的快捷访问入口。疾病标签统计展示不同类型眼疾的病例数量统计，近期诊断以卡片形式展示近期完成的诊断案例。
## 3. 诊断中心模块
用户可对患者信息进行增删改查，进行诊断时可根据诊断量选择个人或批量诊断。其中个人诊断提供左右眼图片上传区域，支持拖拽上传；批量诊断支持选择多个患者进行批量处理，提供文件夹上传功能，支持批量上传多个眼底图像。
## 4. 病例报告模块
展示所有诊断报告基本信息，提供时间筛选和疾病类型筛选功能，支持列表视图和时间轴视图切换。用户可以点击查看报告进入报告详情页，对报告进行编辑、打印、导出等操作。
## 5. 数据分析模块
用户可以查看诊断情况相关图表。其中诊断趋势分析展示最近30天的诊断数据统计，疾病分布分析展示各类眼疾的分布占比，患者年龄分布展示不同年龄段患者的数量分布，患者性别分布展示男女患者比例，辅助医生分析患者群体特征。
## 6. 个人中心模块
用户点击导航栏上的头像进入个人中心，其中个人信息管理展示当前登录医生的个人资料，支持编辑和更新个人信息。修改密码提供密码修改表单，修改完成后自动退出系统重新登录。系统设置提供界面偏好设置。帮助与反馈提供系统使用帮助信息，支持用户提交问题
反馈。
